# 프로젝트 값 확인 · 등록

> 이 스킬은 절차와 멘트 규격만 정의한다. 규칙의 원본은 아래 문서이며, 내용을 이 파일에 복사하지 않는다.
>
> 이 스킬은 문서에 값을 기록할 뿐, 실제 프로젝트 설정 · 패키지를 바꾸지 않는다.

## 참조 문서 (필요 섹션만 읽는다)

- 등록 절차 · 상태 · 미확정 항목 : `Docs/Project Configuration.md`
- 확정 값 : `Docs/Project Values.md`
- 실제 설정 변경 승인 : `Docs/Conventions/Safety/Approval Convention.md`

## 절차

1. 참조 문서를 읽는다.
2. 확인할 항목을 고른다. 착수 확인이면 `착수 시 확정` 항목 전체를, 특정 작업 전이면 그 작업에 필요한 항목만 고른다.
3. 고른 항목을 실제 프로젝트 파일에서 읽기만 해서 확인한다. (예 : `ProjectSettings/ProjectVersion.txt`, `Packages/manifest.json`, `ProjectSettings/ProjectSettings.asset`)
4. `Project Values.md` 또는 `Project Configuration.md` 의 값·상태가 실제 설정과 다르면 차이를 항목별로 보고한다. 기존 문서의 해당 항목을 초기화한 뒤 설정 작업을 진행할지 질문하고 답변을 기다린다. 답변 전에는 문서를 초기화하거나 충돌 항목을 확정하지 않는다.
5. 확인한 값과 질문할 항목을 정리해 보고한다. (멘트 ①)
6. 사용자가 답하거나 승인한 값만 확정한다. 추측한 값은 확정하지 않는다.
7. 승인 후 확정 값을 `Project Values.md` 에 추가하고, `Project Configuration.md` 에서 해당 줄을 지운다. 사용하지 않는 항목은 `Project Configuration.md` 에 `미사용` 으로 표시한다.
8. 결과를 보고한다. (멘트 ②)

## 멘트 규격

① 확인 결과 보고

```
## 프로젝트 값 확인

**실제 설정에서 확인한 값**
| 항목 | 값 | 출처 |
|---|---|---|

**문서와 다른 값** (없으면 생략)
- <항목> : <문서명> <값·상태> / 실제 <값·상태>

**초기화 여부 질문** (차이가 있을 때)
- 위 항목의 기존 문서 값을 초기화한 뒤 실제 설정을 확인해 설정 작업을 진행할까요? 초기화할 항목을 지정해 주세요.

**질문할 항목**
1. <항목> : <질문>

확인한 값을 확정으로 기록할까요?
```

② 등록 후 보고

```
[프로젝트 값] 등록 완료
- Project Values.md 추가 : <항목 목록>
- Project Configuration.md 삭제 · 미사용 표시 : <항목 목록>
- 남은 미확정 항목 : N개
```
