# 참조 관리 컨벤션

## 목적
> AGENT는 Unity 작업시 이 컨벤션을 참고해 객체 의존성과 참조 획득 시점, 예외처리 규칙을 명확히 한 후 작업을 진행한다.

## 선택 기준
- Scene·Prefab의 고정 참조는 [SerializeField] private 할당을 우선 검토한다.
- 루트·자식의 구성과 자식 오브젝트·컴포넌트 참조 배치는 [계층구조 컨벤션](<../Work/Hierarchy Convention.md>)의 `개별 오브젝트·Prefab 구성` 및 `UI 구성`을 함께 따른다.
- 같은 객체의 컴포넌트는 사용 시점과 횟수, 수명에 따라 조회·캐싱 여부를 정한다. 반복 사용하거나 초기화 때 필수 참조를 확인해야 하면 캐싱을 검토한다.
- 런타임 생성 객체는 생성·연결 책임자가 참조를 전달하도록 한다.
- 넓은 범위의 검색이나 Singleton은 필요성과 수명을 확인해 제한적으로 사용한다.
- 단순 호출에 불필요한 Interface·Manager를 추가하지 않는다. 신규 타입은 승인 규칙을 따른다.

## 초기화와 오류
- 참조 캐싱과 초기 상태 설정 위치는 [코드 서식 컨벤션](<Formatting Convention.md>)의 `기본 서식`을 따른다.
- 다른 객체의 Awake·Start 실행 순서를 추측하지 않는다. 필요한 선행 조건과 연결 절차를 정한다.
- 불필요한 예외 처리 기준은 [코드 컨벤션](<Code Convention.md>)의 `3. 로그·예외`를 따른다.
- 필수 참조와 선택 참조를 구분한다.
- 필수 참조 누락 시 의미 있는 오류와 안전한 중단 방식을 정한다.
- 참조가 없을 때의 동작을 임의로 판단하여 구현하지 않고 사용자에게 보고하고 진행한다.
- 객체 교체·파괴·풀 반환 시 참조의 유효성과 정리 책임을 확인한다.
- 풀링 대상의 반환 부모 복원과 상태 초기화는 [계층구조 컨벤션](<../Work/Hierarchy Convention.md>)의 `풀링 대상의 계층과 반환`을 따른다.

## 완료 확인
Inspector 연결 위치·생성 주체·초기화 시점·참조 누락 시 동작을 보고한다.
