# 이벤트 수명 컨벤션

## 목적

> Unity 에서 기본으로 제공하는 event, Action, UnityAction 과 같은 delegate 에 대한 컨벤션 문서이다.
> 
> AGENT는 이 문서를 보고 이벤트 발행·구독의 책임과 종료 시점을 명확히 하여 구현한다.

## 규칙
- 대상이 명확하고 호출 결과가 필요한 단순 통신은 직접 호출을 검토한다.
- 발행자가 구독자를 알 필요가 없거나 여러 객체가 같은 변경에 반응해야 할 때 이벤트를 검토한다.
- 이벤트의 발행 주체·의미·전달 데이터·구독 주체를 정한다.
- 외부에 구독만 허용해야 한다면 event 사용을 검토한다.
- 활성 상태에서만 반응하는 구독은 OnEnable/OnDisable을 기본 쌍으로 검토한다.
- 객체 수명 전체에 필요한 구독은 초기화·종료 경로에 맞게 별도 쌍을 정한다. 모든 이벤트에 같은 쌍을 강제하지 않는다.
- 구독과 해제 코드는 각각 `Bind[Xxx]Event()`와 `Unbind[Xxx]Event()` 형식의 메서드로 나누고, 해당 구독 수명에 맞는 생명주기 메서드에서는 호출만 한다. 활성 상태 구독은 OnEnable/OnDisable, 객체 수명 전체의 구독은 초기화와 종료 경로에 맞춰 호출한다.
- 반복 초기화·활성화에서 중복 구독을 막는다.
- 해제할 익명 함수는 해제 가능한 참조를 보관한다.
- 정적 이벤트나 오래 사는 발행자가 종료된 객체를 계속 참조하지 않도록 정리한다.
- 발행자 교체·Scene 전환·풀 반환 시 해제 책임을 확인한다.
- 즉시 반환값이 필요한 요청과 변경 알림을 구분한다. 모든 직접 호출을 이벤트로 치환하지 않는다.

## 검증
반복 활성화·Scene 재진입·발행자 교체·객체 종료 후 중복되거나 잘못된 호출이 없는지 확인한다.
구독·해제 위치와 이벤트 실행 순서에 대한 가정을 보고한다.
