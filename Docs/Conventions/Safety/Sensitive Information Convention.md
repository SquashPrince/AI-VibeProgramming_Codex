# 민감정보 컨벤션

> 상태: 공통 운영 기준.
> 대상: Unity/C# 기반 AI 보조 개발. 기존 승인 규칙과 사용자 확정 사항을 유지한다.

## 목적
인증정보와 개인정보가 저장소·로그·공유 자료에 포함되는 일을 막는다.

## 규칙
- API 키·토큰·비밀번호·개인키·서비스 계정 인증 파일을 코드에 직접 적지 않는다.
- 비밀 값은 저장소 밖의 승인된 수단으로 주입한다. 구체적인 도구는 프로젝트에서 정한다.
- 공유용 설정 예시는 가짜 값과 필요한 항목명만 포함한다.
- 클라이언트 빌드에 포함되는 설정을 비밀 저장소처럼 취급하지 않는다.
- 요청·응답·오류 로그에서 인증 헤더와 개인정보를 제외하거나 마스킹한다.
- 화면 캡처·Issue·PR·작업 일지·AI 입력에도 비밀 값을 복사하지 않는다.
- 실제 사용자 데이터 대신 허용된 테스트 데이터를 사용한다.

## 노출 의심·발견 시
- 민감정보 노출이 의심되면 다른 조치에 앞서 사용자에게 의심 사실과 확인된 위치를 알린다. 값 자체는 알림에 포함하지 않는다.
- 값을 재출력하지 않고 소유자에게 노출 범위와 위치를 알린다.
- 소유자가 키 폐기·회전 등 필요한 조치를 수행할 수 있게 한다.
- 현재 파일에서 삭제하는 것과 Git 이력·배포본의 노출 제거를 구분한다.
- 이력 재작성이나 강제 푸시가 필요하면 영향과 대안을 보고한다. 관련 Git 작업은 [AI 에이전트 공통 지침](<../../Codex/AgentCommonRules.md>)의 `Git 작업 제한`을 따른다.

## 프로젝트별 값
확정 값은 [프로젝트 값](<../../Project Values.md>), 미확정 값은 [프로젝트 설정](<../../Project Configuration.md>)을 따른다. 미확정 값의 확인 · 등록은 `project-setup` 스킬로 수행한다.
