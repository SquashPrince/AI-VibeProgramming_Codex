# 작업지시서

> 해당 작업이 완료되었음을 사용자를 통해 승인받을 경우.
>
> 기존 파일의 수정/삭제가 필요한 경우, 반드시 사용자의 승인 하에 수행한다.

---

## 작업 목적

- Commit 작성 스킬화.

## 작업 내용

- 워크플로우 상의 Commit 작성을 스킬로 지정한다.
- `AGENTS.md` 에선 온디맨드 참조가 아닌, 스킬 호출을 통해 Commit이 작성될 수 있도록 유도한다.
- 원본 규칙(지침)문서를 삭제하는 것이 아닌, 스킬에서는 관련 지침 문서의 필요 섹션을 읽고 행동을 수행 할 수 있도록 한다.
- 사용자에게 Commit 작성시기 및 내용을 알려 하나의 작업이 너무 오래 끌리지 않도록 유도한다.
- Commit 등록 권유 혹은, Commit 작성 전의 사용자 승인 단계에서,필요한 정보를 간결 하게 표현할 수 있도록 AI-AGENT의 멘트 규격을 스킬에 지정해둔다.
