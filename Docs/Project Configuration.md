# 프로젝트 설정 및 착수 확인

## 목적
> 공통 컨벤션에 프로젝트별 버전·도구·수치를 고정하지 않는다.
>
> 이 문서는 프로젝트마다 복사해 실제 값을 기록하는 설정 양식이다.
>
> 확정된 값은 [프로젝트 값](<Project Values.md>)으로 옮기고, 이 문서에서는 해당 줄을 지운다. 이 문서에는 미확정 값과 절차만 남긴다.

## 등록 절차
1. 프로젝트 착수 시, 현재 작업에 필요한 미확정 값을 확인할 때, 또는 문서와 실제 설정의 차이를 조사할 때 이 문서와 관련 실제 설정·연결 상태를 확인한다.
2. 확인 가능한 값은 출처를 함께 기록한다. `Project Values.md` 또는 이 문서의 값·상태가 실제 프로젝트 설정과 다르면 차이를 항목별로 보고하고, 기존 문서의 해당 항목을 초기화한 뒤 설정 작업을 진행할지 사용자에게 묻는다. 답변 전에는 문서를 초기화하거나 충돌 항목을 확정하지 않는다.
3. 없거나 결정이 필요한 값은 사용자에게 질문한다. 사용자가 답한 값만 확정으로 기록하고, 확정된 값은 `Project Values.md` 로 옮긴다.
4. 현재 작업에 필요한 값은 관련 구현·검증 전에 확정한다. 무관한 항목 때문에 독립 작업을 멈추지 않는다.
5. 아직 프로젝트가 없거나 해당 기능을 쓰지 않으면 각각 착수 시 확정·미사용으로 표시한다. 미사용은 사용자 또는 실제 설정으로 확인한다.
6. 설정 파일·패키지·외부 저장소를 바꾸는 작업은 별도 승인 범위를 따른다. 기록만으로 실제 설정이 변경되지는 않는다.

## 상태와 기록 방식
- 착수 시 확정: 아직 프로젝트에 적용하지 않은 공통 양식의 상태
- 확인 필요: 실제 값 또는 사용자 결정이 필요한 상태
- 확정: 값·출처·확인 날짜를 기록해 `Project Values.md` 로 옮긴 상태 (이 문서에는 남기지 않는다)
- 미사용: 이 프로젝트에서 사용하지 않음을 확인한 상태

각 항목은 값, 상태, 출처/사용자 답변, 확인 날짜를 함께 기록한다. 날짜나 값은 추측하지 않는다.
